## ⚙️ Installation

Clone the repository:

git clone https://github.com/LeoLeiva-dev/portfolio.git

Install dependencies:

composer install

npm install

Create environment file:

cp .env.example .env

Generate application key:

php artisan key:generate

Run migrations:

php artisan migrate

Start development server:

php artisan serve
